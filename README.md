# Mico.Harness

Туториал о том, что такое ИИ-агент на самом деле — где заканчивается модель и начинается harness, где теряются данные, деньги и качество ответов и почему для небольших задач свой harness на 150 строк часто предсказуемее и дешевле готового.

## Что внутри

Пять разделов, 21 минута чтения.

1. Что такое агент — модель думает, harness действует. Граница ответственности.
2. Что опасно — тихие потери, громкие атаки, архитектурные дыры.
3. Что дорого — три статьи расходов, расчёт, граница применимости.
4. Что делать — чек-лист из пяти пунктов, код для 1–3.
5. Выбор модели — процесс, критерии, ориентиры, платформы.

Внутри — схема модель → harness → действия, пример промпт-инъекции, чек-лист безопасности, ориентиры по моделям.

## Для кого

Маркетологи, менеджеры, разработчики, вайб-кодеры. Все, кто собирает агентов и отдаёт им доступ к почте, базе, API. Если вы уже собрали агента или собираетесь — этот туториал сэкономит вам недели.
